# MyChat

一款运行在 Android 上的 AI 聊天伴侣应用。本地配置驱动、多会话管理、支持流式回复与长期记忆。

## 简介

MyChat 让你创建属于自己的 AI 聊天对象。每个对象拥有独立的角色提示词、头像、聊天记录和长期记忆。应用通过 OpenAI 兼容的 `/chat/completions` 接口与任意大模型通信，支持流式输出、思考开关、格式标签解析、通知提醒等功能，所有数据保存在本地 SD 卡，不上传任何服务器。

## 功能特性

### 聊天

- **多会话**：每个 AI 对象拥有独立的提示词、头像和聊天记录
- **流式输出**：边生成边显示，遇到换行符立即发出气泡，无需等待全部完成(适用于本地模型回复慢，模拟真人打字效果)
- **消息状态**：失败消息可点击红色感叹号重发
- **未发送保护**：进程被杀后重启，未发出的消息保留为失败状态
- **消息队列**：连续发送多条时按顺序处理，上一条处理完再处理下一条，避免堵塞或ai无法记忆上条消息
- **默认提示词**：内置默认提示词可以适配应用分消息发送，保存长期记忆，延迟收到的功能。

### 记忆

- **长期记忆**：AI 通过 `save:` 标签主动记录重要信息，每次对话自动带入
- **手动管理**：在对方信息界面查看、添加、编辑、删除每条记忆，或直接编辑 JSON
- **时间戳**：所有记忆自动带 `YYYY/M.D/HH:mm` 格式时间戳

### 界面

- **Material 3**：全面遵循 MD3 设计语言
- **主题色**：内置 12 种预设色，切换后整个应用（含按钮、气泡、卡片、通知）实时变装
- **深色模式**：跟随系统 / 浅色 / 深色
- **共享轴转场**：使用 MD3 MaterialSharedAxis 原生动画
- **头像**：支持上传图片，自动中心裁剪为圆形；未上传时显示彩色文字头像

### 通知与后台（模拟聊天）

- **前台不打扰**：正在查看某个会话时，AI 回复直接显示气泡，不弹通知
- **离开即通知**：切到其它界面、其它会话或后台时，每条 AI 消息弹出通知
- **未读红点**：聊天列表实时刷新，显示最新消息预览与未读小红点
- **点击跳转**：点通知直接进入对应会话
- **后台运行**：发送任务在应用级单例中运行，Fragment 销毁不中断

### 隐私

- **本地存储**：所有配置、聊天记录、记忆、头像存放在 `/sdcard/MyChat/`
- **隐藏后台**：可在系统最近任务列表中隐藏本应用
- **无账号**：不需要注册登录，无任何云端同步

### 调试

- **原始请求查看**：开启调试模式后，用户气泡显示完整发送给 AI 的 payload（含 system 提示词、记忆、历史）
- **原始响应查看**：AI 气泡显示未经解析的完整返回原文（含 `wait:` / `data:` / `save:` 标签）
- **格式检测开关**：发送 / 接收两个独立开关，可控制是否要求 AI 遵循标签格式
